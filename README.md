# Mazingira App

A hyperlocal community events and volunteer‑finder for Nairobi.

## Overview

- **Offline‑first** with WatermelonDB (SQLite)
- **Location‑based** event discovery (expo‑location)
- **Push notifications** for nearby events (expo‑notifications)
- **Backend**: Express + Prisma + PostgreSQL
- **Build**: EAS for Android APK

## Getting Started

```
npm install
expo start --dev-client
```
